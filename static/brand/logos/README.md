# Agentic Reach — Logo Pack

Locked-in brand assets, ready to use.

## Was ist drin

**Mark (Hex Network)** — das Symbol allein
- `mark-color.svg` — Coral/Plum/Yellow auf hellem Untergrund
- `mark-mono-dark.svg` — einfarbig Tinte, für hellen Untergrund
- `mark-mono-light.svg` — einfarbig Weiß, für dunklen Untergrund

**Lockup horizontal** — Mark + "Agentic Reach" nebeneinander
- `lockup-horizontal-color.svg` — Standard
- `lockup-horizontal-color-claim.svg` — mit `// for what's next`
- `lockup-horizontal-mono-dark.svg`
- `lockup-horizontal-mono-light.svg`
- `lockup-horizontal-mono-light-claim.svg`

**Lockup gestapelt** — Mark oben, Wortmarke darunter
- `lockup-stacked-color-claim.svg`
- `lockup-stacked-mono-light-claim.svg`

**Wordmark** — nur die Schrift
- `wordmark-ink.svg`
- `wordmark-white.svg`

## Format

- **`*.svg`** — verlustfrei, beliebig skalierbar. Erste Wahl für Web, Print und alles andere. Schriften (Space Grotesk, JetBrains Mono) werden via Google Fonts eingebunden — wenn die Datei offline gerendert werden muss, vorher in einem Editor (Figma, Illustrator, Inkscape) öffnen und Schriften in Pfade umwandeln.
- **`png/*.png`** — 64–1600px Breite, transparenter Hintergrund. Für Anwendungen, die kein SVG akzeptieren (Office, manche Tools, Social).

## Schutzraum

Mindestens die Höhe eines Mark-Knotens (≈ 1/8 der Mark-Höhe) rundherum freihalten. Auf gemusterten Hintergründen ggf. mehr.
